# TH-Relay-Note
该项目旨在提供一个油猴脚本，以实现便捷地接力信息记录以及数据导出

# 功能
## 接力记录
用户在BiliBili的动态、专栏、视频页面的时候可以通过界面侧边的面板呼出插件的菜单，通过菜单可以便捷创建一个接力项目。在创建菜单可以指定接力项目的名称、主催昵称和主页链接、活动年月日等信息。在创建后默认直接绑定创建的项目，后续任何接力棒记录都会直接添加到绑定的项目中，除非手动更改。

## 棒记录
用户在BiliBili的动态、专栏、视频页面的时候可以通过界面侧边的面板呼出插件的菜单，通过菜单可以便捷创建一个棒。在创建菜单中可以指定棒的作者、作者主页链接、作品链接、作品类型（视频、插画、文章、MMD、）、接力棒数（普通自然数棒数和特殊的EX棒）、接力时间。同时可以设定添加到的项目（默认添加到绑定的项目中）。对于作者昵称、作者主页链接、作品链接是自动获取并填充的（如果在动态、专栏、视频页面），也可以自行更改

## 项目管理
在项目管理页面可以管理项目中的棒。可以对一个项目进行：
- 添加：添加一个棒，与[棒记录](##棒记录)功能相同
- 删除：删除一个棒，在尝试删除的时候会显示二次确认弹窗以防止误操作
- 排序：对棒进行排序。在排序的时候会自动编辑排序后的棒的序号（普通棒和EX棒相互独立，不共享一个排序序号），同时也可以选择非重排序号的排序。
- 编辑：编辑一个棒的信息，打开的界面和添加的相同，不过它的信息因为已经存在了所以应当填充。

同时，也可以对项目进行：
- 添加：添加一个项目，与[接力记录](#接力记录)功能相同
- 删除：删除一个项目，在尝试删除的时候会显示二次确认弹窗以防止误操作
- 编辑：编辑一个项目的信息，打开的界面和添加的相同，不过它的信息因为已经存在了所以应当填充。
- 导出：导出项目的内容为md文件（具体导出规范在[导出规范](#导出规范)给出）

## 设置
设置页包括：
- 棒类型设置：可以用来管理当前的棒类型以及增删棒改类型
- 导出设置：可以用来管理导出的路径（是否使用FileAccessAPI）

# 导出规范
### 导出逻辑
从第一棒开始，依次按照模板生成，从meta信息开始，到普通棒，再到EX棒结束。
生成完成后，如果开启了FileAccessAPI（下文将指向的root路径统称为root），则直接按照`root/<项目名称_年份_月份>.md`来生成，如果文件已存在，则将原文件改为`<项目名称_年份_月份>.md.1`（后缀数字依次递增）再生成。

### 导出格式规范
对于一个标准的md导出文件，它应该是以下格式的：

```markdown
## 宣传

主催 [XXX](https://space.bilibili.com/123456789)

宣：[查看](https://t.bilibili.com/123456789)

## 整点接力

### 第1棒 9:00

创作者 [@XXX](https://space.bilibili.com/123456789)

插画 [查看](https://t.bilibili.com/123456789)

---

### 第2棒 10:00

创作者 [@XXX](https://space.bilibili.com/123456789)

图片 [查看](https://t.bilibili.com/123456789)

---

……

---

### 第EX1棒 13:44

创作者 [@XXX](https://space.bilibili.com/123456789)

插画 [查看](https://t.bilibili.com/123456789)

---

### 第EX2棒 13:50

创作者 [@XXX](https://space.bilibili.com/123456789)

视频 [查看](https://t.bilibili.com/123456789)

---
```

其中，起始为固定形式，

```markdown
## 宣传

主催 [XXX](https://space.bilibili.com/123456789)

宣：[查看](https://t.bilibili.com/123456789)
```

其中宣根据宣传的数量，有

```markdown

一宣：[查看](https://t.bilibili.com/123456789)
二宣：[查看](https://t.bilibili.com/123456789)
三宣：[查看](https://t.bilibili.com/123456789)
……
终宣：[查看](https://t.bilibili.com/123456789)
```

这种形式，一二三视情况而定，最后一个一定是终宣，如果只有一个则只有终宣。

然后是普通棒，也是固定的格式，以“## 整点接力”开头为一MD节
然后是固定的

```markdown
### 第1棒 9:00

创作者 [@XXX](https://space.bilibili.com/123456789)

插画 [查看](https://t.bilibili.com/123456789)
```

按照次序1、2、3、……这样排下去，第N棒后面空一格接棒的时间（24小时制）。然后是创作者昵称（使用@标出）超链接和作品类型（后面统一显示文本为查看的超链接）。EX棒也一样，不过棒号变成了“EXN”这种类型（N为序号），需要注意EX棒永远全部位于普通棒之后，也按照次序排序生成。每个棒之间通过“---”分隔。

### 特殊情况
在导出的时候需要按照棒号逐个生成，那么自然会遇到某个序号的棒不存在的情况，这个情况下依然按照模板生成棒文本内容，但是除了棒序号外其他都标注“N/A”（即未知）。
